# 🤖 ia

Aplicação front-end com integração de componentes inteligentes, desenvolvida em **TypeScript** e **React**. O projeto utiliza uma stack moderna de UI com visualização de dados e suporte a calendário.

## 🚀 Tecnologias

| Tecnologia | Descrição |
|---|---|
| TypeScript | Linguagem principal |
| React | Biblioteca de interface |
| Radix UI | Componentes acessíveis (Accordion, Tooltip) |
| Recharts | Gráficos e visualização de dados |
| Axios | Requisições HTTP |
| React Day Picker | Seletor de datas |
| React Scripts | Scripts de build e desenvolvimento |

## 📁 Estrutura do Projeto

```
ia/
├── ia/               # Código-fonte principal

```

## ⚙️ Como Executar

### Pré-requisitos
- Node.js instalado
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/gabrielkras1/ia.git
cd ia

# Instale as dependências
npm install
```

### Executando o projeto

```bash
npm start
```

A aplicação estará disponível em `http://localhost:3000`.
